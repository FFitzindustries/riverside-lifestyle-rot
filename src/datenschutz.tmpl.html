Wenn du uns per E-Mail oder Telefon kontaktierst, bearbeiten wir die übermittelten Daten zur Beantwortung deiner Anfrage. Eine Weitergabe an Dritte erfolgt nicht ohne deine Einwilligung.

4. Schriftarten

Diese Website bindet alle Schriftarten lokal von unserem eigenen Server ein. Es werden keine Schriften von Google Fonts oder anderen externen Anbietern nachgeladen. Beim Besuch dieser Seite wird deine IP-Adresse dadurch an keinen Schriftanbieter übertragen.

Die Hintergrundvideos werden direkt von dieser Website ausgeliefert (kein externer Video-Dienst, kein Tracking durch Dritte).

Diese Website setzt aktuell keine Tracking-Cookies und kein Analyse-Tool ein.
